Architectural Excellence

Designed for resource-constrained agent pipelines where latency is critical

Sub-5ms Semantic Scanning

Leverages native Model2Vec representation layers. Scans thousands of normalized code embeddings instantly using SIMD autovectorization on standard CPU hardware.

AST Structural Boundaries

Tree-sitter integration understands your code structure. It avoids breaking functions or classes across lines, delivering meaningful blocks directly to LLM context windows.

Hybrid Lexical-Semantic Core

Exact identifier matches are critical in code. BM25 indexes ensure query keywords map cleanly while Model2Vec embeddings cover intent and conceptual overlaps.

Drop-in MCP stdio protocol

Launches naturally as a Model Context Protocol server over stdio. A seamless local addition for developer environments like Claude Code, Cursor, or Cline.

Quick Start & Setup

Deploy the high-performance local server in seconds

bash — install & configure mcp
# 1. Compile the native release binary from source
$cargo build --release
# 2. Install the CLI tool directly to cargo path
$cargo install --locked --path .
# 3. Add to your local Claude Code configuration as an MCP stdio server
$claude mcp add semble -s user -- semble
# 4. Or search programmatically from the CLI
$semble search "authentication flow" ./src
